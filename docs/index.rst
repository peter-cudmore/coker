Coker
=====

Coker is a mathematical programming toolkit for technical computing in Python.
Define a model as a Python callable, trace its supported operations into a
symbolic representation, and execute it through a chosen backend.

Start with :doc:`basics/index` for installation and a first result. Follow the
:doc:`tutorials <tutorials/index>` to learn function construction, or use the
:doc:`how-to cookbook <how_to/index>` to solve a specific task. Read
:doc:`architecture/index` for the execution model and :doc:`api/index` for
interface contracts.
