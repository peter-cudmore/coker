Adjacent limbs exchange explicit data structures and archives; they must not reach across layers through helper calls.

## Coker backend efficiency

- [ ] **Complete ordinary-phase ping-pong workspace banking.** This is the primary Coker backend efficiency and CI-recovery task: compile live frontiers into two disjoint caller-workspace banks, gather only live-through values at phase boundaries, and emit B/N/Case/Call/gather phases that never write their read bank. The sole same-span exception is a certified residual update with source ownership transfer. See `docs/lowering_bytecode_tdd/phase_06_nonlinear_calls_and_tangents.md`; `residual_runtime_migration_plan.md` is superseded for ordinary workspace placement.
- [ ] **Make the efficiency decision from target-relevant measurements.** Record artifact size, peak primal/tangent workspace, bytes touched, explicit-copy rows, bilinear rows/terms, and target or faithful-target median/p95/worst-case execution. Do not accept host-only construction timing as embedded-runtime evidence.
- [ ] **Finish QP update-path measurement and specialization.** Follow `docs/qp_performance_review.md`: time evaluator, CSC scatter, vector/matrix update, and solve; then bind immutable coefficients once and update only parameter-dependent streams when the measurements justify it.

## Broader 0.4 file-layout work

- [ ] **Split `src/coker/algebra/kernel.py` (1,205 lines).** Isolate dimension/value classification, tape storage and tracing, tracer operators, function binding/evaluation, conditionals, and trace context. Preserve `Tape`, `Tracer`, and `Function` as the explicit data path between these modules; do not create cross-module operation helpers that bypass the tape.
- [ ] **Define one backend-lowering contract and rename backend-specific exceptions.** `Backend.lower` promises a repeated-evaluation callable over signature-shaped input/output lists, but Coker returns `CokerFunction` with bytecode/export methods, CasADi has a separate module-level `lower` that returns symbolic `(inputs, outputs)`, NumPy returns a planned closure, and JAX/SymPy inherit the generic evaluator closure. Split symbolic export from executable lowering: introduce typed `LoweredFunction`/`SymbolicExport` protocol objects (or equivalent explicit methods), make every backend return the executable contract from `lower`, and give symbolic CasADi/SymPy APIs names that cannot be mistaken for lowering. Backend fallbacks must declare the capability they lack and use the common evaluator explicitly; they must not silently lower through another backend.
- [ ] **Make lowering capabilities explicit and test them uniformly.** Encode support for module calls, `FunctionSpace` inputs, absent outputs, symbolic export, repeated execution, and artifact compilation as declared backend capabilities. Exercise the same input/output shape, scalar conversion, and fallback/error contract for NumPy, CasADi, Coker, JAX, and SymPy. Coker's artifact/bytecode methods remain Coker-specific extensions on its lowered object, not a different meaning of `lower`.
- [ ] **Implement and test CasADi variational path inequalities.** `VariationalProblem.path_constraints` are retained only for post-solve reporting; `create_variational_solver` currently appends terminal constraints but never transcribes path constraints at collocation points. Define the boundary convention for every interval endpoint, append each residual and its bounds to the NLP, and cover feasible, active, and infeasible scalar/vector inequalities.
- [ ] **Keep runtime modules shaped by execution, not representation.** `coker-bytecode` owns archive types and validation; `coker-compiler` transforms typed exports into archived programs; `coker-runtime` maps and executes archived programs; `coker-osqp-ffi` owns solver ABI bindings. Remove any reverse dependency or import that makes a lower layer invoke a higher layer directly.
- [ ] **Enforce the size rule in review.** New or materially changed Rust/Python files over 1,000 lines require a documented cohesion exception. Tests, generated tables, and tightly coupled state machines may be exceptions only when their execution boundary is clearer than a split.

## Completion criteria

- Every Rust and Python source file above 1,000 lines is either split by the execution/data boundary or has an explicit, reviewed cohesion exception.
- The changed Coker/QP path is navigable in execution order without opening unrelated behaviours.
- Mapped runtime execution remains borrowed, aligned, caller-buffered, allocation-free after construction, and `no_std` compatible.
- The targeted Python and Rust tests for each moved limb pass unchanged in behaviour.
