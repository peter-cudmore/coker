# Higher-order DAE analysis

## Goal

Extend `coker.dynamics` system analysis beyond semi-explicit index-one DAEs
without broadening the public model representation to fully implicit residual
systems. The supported form remains:

\[
\dot{x} = f(x, z, u, p), \qquad 0 = g(x, z, u, p), \qquad y = h(x, z, u, p).
\]

Here, `x` is the differential state, `z` is the algebraic state or multiplier,
`u` is a known control, and `p` is the parameter vector. Fully implicit DAEs,

\[
F(t, x, \dot{x}, u, p) = 0,
\]

are explicitly out of scope for 0.5.

## Problem

The current index-one path requires a square, generically nonsingular
\(g_z\), then derives tangent fields and constrained gradients by linear
solves against that Jacobian. This excludes valid semi-explicit higher-index
systems: an algebraic variable can become solvable only after differentiating
a constraint along the dynamics.

The same limitation excludes common nonholonomic multiplier models. In
particular, \(g_z\) is singular if `z` is a reaction multiplier and the
constraint is velocity-level rather than a direct equation for that multiplier.

## Normalization

Introduce a symbolic semi-explicit DAE normalization layer. It must retain:

- every original algebraic constraint;
- each selected total derivative of a constraint;
- its differentiation order and source constraint;
- input jets required by differentiated controlled constraints; and
- all generic regularity conditions used to solve the normalized system.

For a constraint \(g\), selected prolongation has the form:

\[
g^{[0]} = g, \qquad g^{[k+1]} = \frac{d}{dt}g^{[k]}.
\]

Structural incidence and matching choose the constraints to prolong. A
nonzero symbolic determinant then verifies that the selected prolonged
equations determine the unresolved algebraic variables. Structural matching
is only a candidate-selection mechanism; it is not a proof of regularity.

The normalized system must retain both original and derived constraints so
that analysis only considers consistent states. It must never silently replace
the original DAE with an unconstrained ODE over its ambient coordinates.

## Controlled constraints

A constraint that depends on a known input produces input derivatives after
prolongation:

\[
\dot g = g_x f + g_z \dot z + g_u \dot u.
\]

Represent \(u, \dot u, \ddot u, \ldots\) as explicit known input jets through
the required order. Never assume a derivative is zero. Controlled
identifiability remains inconclusive until its descriptor-system treatment is
implemented; this work only supplies correct normalization data for a future
analysis.

## Consistent-manifold geometry

Generalize the index-one-specific constraint geometry into a geometry built
from the regularized prolonged system. It must provide:

- admissible tangent fields;
- output differentials restricted to the consistent manifold;
- the intrinsic rank target of that manifold; and
- all nonzero regularity conditions.

Implement every symbolic solve with linear-system operations. Do not construct
explicit symbolic inverses.

Observability and identifiability must use the intrinsic dimension after
constraint reduction, not the count of ambient state, multiplier, and derived
variables. Report regularity determinants together with rank witnesses in
`AnalysisResult.rank_conditions`.

## Nonholonomic mechanics

The first production target is the semi-explicit Lagrange--d'Alembert form:

\[
\dot q = v,
\qquad
M(q)\dot v = Q(q, v, u) + A(q)^\mathsf{T}\lambda,
\qquad
A(q)v = 0.
\]

Set \(x=(q,v)\) and \(z=\lambda\). The velocity constraint does not directly
determine \(\lambda\). Differentiate it once:

\[
A(q)\dot v + \dot A(q,v)v = 0.
\]

Then solve the saddle system:

\[
\begin{bmatrix}
M(q) & -A(q)^\mathsf{T}\\
A(q) & 0
\end{bmatrix}
\begin{bmatrix}
\dot v\\
\lambda
\end{bmatrix}
=
\begin{bmatrix}
Q(q,v,u)\\
-\dot A(q,v)v
\end{bmatrix}.
\]

Its generic nonzero determinant is a regularity condition. Do not integrate
\(A(q)\dot q=0\) into a position constraint: a nonholonomic velocity
constraint is generally nonintegrable, and that conversion changes the model.

Accessibility must operate on the admissible distribution and evaluate rank
on the consistent manifold. Lie brackets may generate directions outside the
instantaneous constraint distribution; retaining those directions is required
for a correct nonholonomic accessibility result.

## Delivery sequence

1. Define the normalized semi-explicit DAE data model, provenance, regularity
   conditions, and input-jet representation.
2. Implement bounded structural prolongation and symbolic regularity checks.
3. Implement consistent-manifold tangent and differential operations.
4. Migrate observability and identifiability to the normalized geometry.
5. Support one-prolongation nonholonomic multiplier systems.
6. Generalize to bounded multi-level semi-explicit prolongation.
7. Design fully implicit residual DAE support separately after this work.

## Regression models

- An index-two pendulum with a holonomic position constraint. Verify
  prolongation, multiplier recovery, and rejection of inconsistent states.
- A rolling disk or knife-edge with
  \(-\sin\theta\,\dot x + \cos\theta\,\dot y = 0\). Verify that it remains a
  velocity constraint and retains bracket-generated accessibility directions.
- A control-dependent constraint requiring \(\dot u\). Verify that no
  constant-input assumption enters normalization.
- Singular and rank-changing examples. Verify `rank_conditions` includes the
  appropriate regularity determinant and rank witness.
